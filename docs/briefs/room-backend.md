## Verified API shapes (from the passing spikes — use these, don't guess)
- Streaming transcription: `genai.Client(http_options={"api_version": "v1beta"}).aio.live.connect(model=MODEL_IDS["room_transcribe"], config={"input_audio_transcription": {}})`. **No diarization** (rejected in live mode). Send `await s.send_realtime_input(audio=types.Blob(data=pcm, mime_type="audio/pcm;rate=16000"))`. Receive loop: `msg.server_content.interim_input_transcription.text` = partial caption; `msg.server_content.input_transcription.text` = **final utterance** (arrives at end of speech). `s.receive()` yields one turn then ends → wrap it in `while True:`.
- Decisions gate: `beta().decisions.create(model=MODEL_IDS["decisions"], input=[text_part(...)], questions={"is_challenge": {"type":"noul","instructions":"Is this utterance a judge's question or challenge to the founder that needs a substantive answer (not small talk, logistics, or the founder speaking)?"}, "topic": {"type":"choice","instructions":"What is the utterance mainly about?","criteria":{"market":"market size or demand","price":"pricing or willingness to pay","competitors":"incumbents or alternatives","tech":"how it works or can be built","traction":"users, churn, revenue, retention","other":"anything else"}}})` → `answers["is_challenge"].noul`, `answers["topic"].choice`. Put a 1-line pitch summary in the input text.
- Live twin token: exactly like `spike_room_live.py`: v1alpha client, `types.CreateAuthTokenConfig(uses=1, expire_time=now+30min, new_session_expire_time=now+2min, live_connect_constraints=types.LiveConnectConstraints(model=MODEL_IDS["live_voice"], config=types.LiveConnectConfig(response_modalities=["AUDIO"], system_instruction=..., tools=[challenge_founder tool], output_audio_transcription={})))`; return `token.name`.
- TTS fallback: reuse `boardroom._synthesize_wav(text, voice_name, wav_path)`.

## `backend/pipeline/room.py`
Per-run state `ROOMS: dict[run_id, RoomState]` (seats/roles, recent twin challenge texts with timestamps, pending utterances awaiting a live twin, room start time, stage_changed emitted flag).

1. **Evidence pack** `build_evidence(log.events) -> dict` from the run's events (works for runs loaded from disk): analyst `launch_probability` + `analyst_reason`, `market_intent`, swarm `rubrics`, lab outcomes (n converted / n quit + each quit_reason), competitors (title + price), spec (headline, price, risks), verdict failure_modes, pitch title/one_liner. Also `evidence_text(evidence) -> str` (compact, every number written once, both as decimal and percent when it's a 0–1 value, e.g. "trust 0.23 (23%)").
2. **`async def stream_audio(run_id, websocket)`** for `WS /ws/runs/{run_id}/room-audio`: emit `stage_changed {stage:"room"}` once per run; open the transcription session; forward binary frames; on partial captions emit `room_caption` (throttle to ≤ 4/s); on final text → `handle_utterance(run_id, text)`. If the Live session closes or errors, reopen it (sessions can expire); stop when the client disconnects.
3. **`async def handle_utterance(run_id, text, forced=False)`**: emit `room_utterance` (`speaker:"unknown"`, `speaker_label:""`, `t` since room start, id `u_<8hex>`). **Echo filter:** skip (no gate) if `difflib.SequenceMatcher` ratio ≥ 0.6 against any twin challenge from the last 45 s. Gate (to_thread) → emit `room_gate` with `latency_ms`; `triggered = forced or is_challenge >= 0.7`. If triggered: register it as pending and start `_server_fallback_after(run_id, utterance_id, text, delay=7)`.
4. **`twin_token(run_id, seat) -> dict`**: system instruction = "You are the digital twin of judge seat {seat}, a {role} at a live startup pitch. When the judge's words arrive, say ONE short spoken challenge (max 2 sentences, sharp and specific to this startup) AND call challenge_founder with exactly that text. Use these facts from our analysis when relevant: {evidence_text}". Tool `challenge_founder({challenge: string})`. Return `{"ephemeral_token","model","system_instruction"}`.
5. **`async def post_challenge(run_id, seat, text, utterance_id, source="live", audio_url=None)`**: mark the utterance as answered (cancels the fallback), remember the text for the echo filter, emit `twin_challenge` (`challenge_id` `c_<8hex>`, role from seats, default roles: seat 1 "VC partner", 2 "Skeptical CFO", 3 "AI engineer"), then `await founder_brief(...)`.
6. **Server fallback** `_server_fallback_after`: sleep `delay`; if still pending → challenge text via `generate_text(MODEL_IDS["room_twin"], ..., thinking="low")` (same instructions as the twin), TTS to `room/<challenge_id>.wav` (voice "Fenrir"), then `post_challenge(..., source="server", audio_url=ctx.artifact_url(...))`. Seat = round-robin.
7. **`async def founder_brief(run_id, challenge_id, challenge_text, t_start)`**:
   - In parallel: (a) Decisions call — `{"support": {"type":"choice","instructions":"Given ONLY the evidence from our own analysis, how well does it let the founder answer this challenge?","criteria":{"verified":"the evidence directly supports a strong answer","partial":"the evidence supports part of an answer or is mixed","push_back":"the evidence agrees with the challenge; the founder should concede and give the fix"}}}` with input = evidence_text + challenge → badge `VERIFIED`/`PARTIAL`/`PUSH_BACK`, `badge_confidence` = that answer's confidence; (b) `generate_json(MODEL_IDS["room_founder"], ..., thinking="low")` → `{"line": string (≤ 14 words, first person, speakable), "proof": [{"label","value","source"}] (1–2 items, values copied from the evidence)}`.
   - **Number checker (code, not model):** for each proof pill, extract all numbers from `value` (regex, strip `$ , %`); every number must appear in the evidence numbers set (compare with tolerance 0.005, and treat `23` ≡ `0.23` for percents). Drop failing pills; if none remain, add one pill built directly from the evidence (the lowest swarm rubric, e.g. label "Lowest buyer score", value "credibility_trust 0.23"). Count dropped pills in a module counter `CHECKER_STATS = {"pills": n, "dropped": m}` and log it.
   - Trim `line` to 14 words. Emit `founder_brief` with `latency_ms` from the utterance (or challenge) time. Stage for all room events: `"room"`.
