# V2 "fix it, then prove the fix" — contract v3 (2:00 PM). Additive.

Runs automatically after `verdict` (new stage `iterate`), and on demand for any saved run via `POST /api/runs/{run_id}/iterate` → `{ "ok": true }`.
Takes ~4–5 min in the background; never blocks the verdict.

## Flow
1. **Plan** (`gemini-4-carbon`): turn the verdict's failure modes + lab quit reasons + lowest swarm rubrics into ≤ 3 concrete page changes. **Honesty rule:** no invented facts — no fake reviews, testimonials, addresses, certifications or photos; anything needing a real fact goes to `founder_todo`, never onto the page (tested: visible placeholders lowered trust 0.35 → 0.25).
2. **Patch** (Antigravity Managed Agent): continues **the same sandbox session that built V1** (`previous_interaction_id` + `environment_id`) when available; otherwise a fresh managed-agent run given the V1 file. Fallback: Hydrogen.
3. **Prove**:
   - **Held-out A/B:** 6 personas that never saw anything (`backend/personas_holdout.json`) visit **V1 and V2 in parallel**.
   - **Swarm re-score:** the same 200 buyer personas, same 5 Decisions rubrics, on the V2 screenshot.
4. **Result**: conversions V1 vs V2 on the held-out panel + rubric deltas. The analyst launch probability is **not** changed (it scores the idea, not the page) — the UI should say so.

## Events (stage `"iterate"`)

| `type` | `data` |
|---|---|
| `stage_changed` | `{ "stage": "iterate" }` |
| `v2_plan` | `{ "fixes": [{ "issue": string, "change": string, "evidence": string }] (1–3), "founder_todo": [string] (0–3: real-world items only the founder can provide — real photos, identity, address — never faked on the page) }` |
| `v2_build_progress` | `{ "message": string }` |
| `v2_ready` | `{ "url": string, "screenshot_url": string, "v1_screenshot_url": string, "reused_sandbox": bool }` |
| `v2_panel_finished` | `{ "persona_id", "name", "version": "v1" \| "v2", "outcome": "converted" \| "quit", "quit_reason": string \| null, "video_url": string }` |
| `v2_result` | `{ "holdout": { "n": 6, "v1_converted": int, "v2_converted": int }, "rubrics_v1": { "<rubric>": number }, "rubrics_v2": { "<rubric>": number }, "summary": string }` |

UI: a "V2" card — V1 vs V2 screenshots side by side, the ≤ 3 fixes, "Held-out buyers: 2/6 → 4/6", and the rubric bars before/after (trust is usually the headline). Persona videos for both versions are clickable.
